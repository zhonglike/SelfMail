# 客户端配置指南

所有客户端的配置模式完全一致：**IMAP 收 + SMTP 发，登录名是完整邮箱地址**。
Webmail 里的「自动配置」端点已内置，Thunderbird/Outlook/Foxmail 输入邮箱+密码即可自动填好。

## 服务器信息（所有客户端通用）

| 协议 | 服务器 | 端口 | 加密 |
|---|---|---|---|
| IMAP | mail.example.com | 993 | SSL/TLS |
| SMTP | mail.example.com | 465 | SSL/TLS |
| SMTP | mail.example.com | 587 | STARTTLS |
| POP3 | mail.example.com | 995 | SSL/TLS |

用户名：`用户名@example.com`（完整邮箱）。自签名证书阶段客户端提示不信任时选择「继续/信任」。

## Windows

**Thunderbird**：首启输入邮箱地址 → 自动发现（autoconfig）→ 输入密码完成。
**Outlook**：文件 → 添加账户 → 高级选项勾选手动 → IMAP → 按上表填写。
**Foxmail**：右上角 + → 新建账号 → 手动设置 → 按上表填写。

## 安卓

**Outlook / Gmail App / K-9 Mail**：添加账户 → IMAP → 填服务器与凭据。
Gmail App：设置 → 添加其他账户 → 其他(IMAP/POP3)。

## iOS 邮件

设置 → 邮件 → 账户 → 其他 → 添加邮件账户 → IMAP，按上表填写。

## 常见问题

| 现象 | 原因/解决 |
|---|---|
| 收发都提示密码错误 | 用的是「完整邮箱地址」登录了吗；管理员后台确认账号 active |
| 发信一直转圈 | 25 出站被封 → config 里 `outbound.mode` 改 relay；或用 465 端口提交 |
| 收不到外部来信 | MX/A 记录未生效；路由器 25 端口转发缺失；运营商封 25 入站 |
| 信进对方垃圾箱 | SPF/DKIM/DMARC 没配齐或未生效；用 mail-tester.com 打分定位 |
| 证书不受信任警告 | 换 Let's Encrypt 证书（部署指南 §4），或客户端信任自签名证书 |
| IMAP 频繁断线 | 正常；客户端会自动重连。服务器 IDLE 推送会减少轮询 |
