# 安全加固清单

SelfMail 的默认策略已经是「安全优先」，以下是纵深加固建议。

## 已内置的安全机制

- **口令存储**：scrypt（N=2^14, r=8, p=1）加盐散列，库被拖走也无法逆推
- **认证必须加密**：465/587/993/995 上禁止明文口令；143/110 必须先 STARTTLS（`security.require_tls_for_auth`）
- **防开放中继**：25 端口只投递本域收件人；任何外域 RCPT 一律 550 并记录日志
- **登录限速**：连续失败 ≥5 次封禁该 IP 30 分钟（`security.max_auth_fails/ban_minutes`）
- **CSRF**：Web 所有写操作要求 `X-CSRF` 头，会话 Cookie HttpOnly+SameSite=Strict
- **HTML 邮件消毒**：服务端剥离 script/事件属性，前端再用 sandbox iframe 渲染
- **DKIM**：所有出站邮件自动签名，防止冒名与拒收
- **路径穿越防护**：Web 静态文件与附件路径白名单化

## 建议的管理员加固

1. **换真 TLS 证书**：自签名只适合内网体验期（部署指南 §4）
2. **改掉默认 2048MB 配额**：按磁盘实际容量规划，防止单账号塞爆
3. **定期备份 `data/`**：一个目录包含全部数据（SQLite + 邮件文件 + DKIM 私钥）
   ```powershell
   robocopy data D:\backup\selfmail /MIR /R:2 /W:5
   ```
   DKIM 私钥丢失 = 需要换 selector 重新配 DNS
4. **不要把 25 端口暴露的家庭宽带当生产环境**：家宽 IP 信誉差，信容易被判垃圾；生产建议云服务器或 relay 模式
5. **关闭 POP3**（不用就 `pop3.enable=false`）：减少暴露面
6. **失败日志巡检**：管理后台日志页按 level=warn 过滤，关注 `smtp_auth_fail`、`relay_denied`、`web_login_fail` 的高频 IP
7. **升级习惯**：关注 Python 与 cryptography 安全通告；SelfMail 本体零第三方运行时依赖（除 cryptography/dkimpy）

## 已知边界（诚实声明）

- 邮件正文 anti-spam/病毒扫描未内置（个人/小团队自用可接受；接入 ClamAV 可在收信管线加钩子）
- 未实现 SMTP `BURL`/`EXCHANGE` 等冷门扩展；IMAP 未实现 CONDSTORE/QRESYNC（主流客户端不依赖）
- Webmail 为纯文本编辑器，不支持富文本撰写
