# SelfMail 部署指南

从零把自邮跑起来，覆盖三种典型环境：家里 Windows 主机、家里 Linux 主机、云服务器。

## 0. 前置条件（一次说清）

| 条件 | 说明 | 检查方法 |
|---|---|---|
| 公网 IP | 25 端口入站/出站未被运营商封锁 | 云服务器一般没问题；家宽见下 |
| 一个域名 | 例如 example.com，DNS 控制权在你手里 | — |
| 端口 | TCP 25/465/587/143/993/110/995/443 | `Test-NetConnection` / `telnet` |
| Python 3.10+ | Windows 官网安装包；Linux 一般自带 | `python --version` |

**家宽用户重点**：国内三大运营商基本都封 25 端口入站与出站。
- 出站被封（发不出去）：把 `config.json` 的 `outbound.mode` 改为 `relay`，走上级中继（一台便宜的 VPS 装 Postal/Mailcow，或商业 SMTP 服务），SelfMail 自动排队经中继投递。
- 入站被封（收不到）：云上只跑一台「入站网关」把 25 端口流量转发回家，或干脆全跑在云上。
- IP 是动态的：必配 DDNS（`scripts/win/ddns-cloudflare.ps1`），A 记录 TTL 越短越好。

## 1. Windows 部署（推荐路径）

```powershell
# 管理员 PowerShell
cd SelfMail 项目目录
powershell -ExecutionPolicy Bypass -File scripts\win\install-windows.ps1
```

脚本自动完成：Python/虚拟环境/依赖 → 防火墙 8 个端口 → 交互生成配置与管理员 → 注册开机自启计划任务（崩溃自动拉起）→ 打印需要去域名商配置的 DNS 记录。

### 路由器端口转发（NAT 环境）
外部 TCP 25/465/587/143/993/110/995/443 → 服务器内网 IP 同端口。转好后验证：
`https://mxtoolbox.com/SuperTool.aspx` 逐项查 `SMTP`、`Reverse Lookup`。

### 动态 IP：DDNS
```powershell
# 编辑 ddns-cloudflare.ps1 里的 Token/Zone/Record 后：
powershell -ExecutionPolicy Bypass -File scripts\win\register-ddns.ps1
```

## 2. Linux 部署

```bash
cd SelfMail
python3 -m venv .venv && .venv/bin/pip install cryptography dkimpy
.venv/bin/python -m selfmail init          # 交互生成配置与管理员
sudo .venv/bin/python -m selfmail gen-dns  # 输出 DNS 记录清单
sudo setcap 'cap_net_bind_service=+ep' .venv/bin/python   # 允许绑 25/443
.venv/bin/python -m selfmail serve
```

systemd 单元（`/etc/systemd/system/selfmail.service`）：

```ini
[Unit]
After=network-online.target
[Service]
WorkingDirectory=/opt/selfmail
ExecStart=/opt/selfmail/.venv/bin/python -m selfmail serve
Restart=always
[Install]
WantedBy=multi-user.target
```

## 3. DNS 记录（收进白名单的灵魂）

在域名 DNS 控制台添加（`python -m selfmail gen-dns` 会生成你自己的实际值）：

| 类型 | 主机 | 值 | 作用 |
|---|---|---|---|
| A | mail.example.com | 你的公网 IP | 收发信入口 |
| MX | example.com | 10 mail.example.com | 告诉全世界把信送到你这里 |
| TXT | example.com | v=spf1 mx a -all | SPF：防伪造 |
| TXT | s1._domainkey.example.com | v=DKIM1; k=rsa; p=… | DKIM 公钥（超过 255 字符需分段） |
| TXT | _dmarc.example.com | v=DMARC1; p=quarantine; rua=mailto:… | DMARC 策略 |
| CNAME | autoconfig.example.com | mail.example.com | Thunderbird 自动配置 |

配完后在 Webmail 管理后台点「在线核查 DNS」，逐项核对是否全球生效（生效一般 5-30 分钟）。

## 4. TLS 证书升级（从自签名到 Let's Encrypt）

自签名证书开箱能用（客户端需信任一次）；正式使用建议换真证书：

```powershell
# Windows: 用 win-acme (https://www.win-acme.com) 申请，选 PEM 输出
wacs.exe --source manual --target mail.example.com --store pemfiles --pemfiledir data\certs
# Linux: certbot certonly --standalone -d mail.example.com
# 然后把 config.json 的 tls.cert/key 指向 fullchain.pem / privkey.pem，重启服务
```

## 5. 验收清单
